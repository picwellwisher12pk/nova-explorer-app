Engineered For Performance

Built like a compiler, designed like high-end hardware.

Most file managers are bogged down by web runtimes or decades-old legacy code. Nova Explorer was written from scratch to give power users immediate feedback with uncompromised ergonomics.

Multithreaded Rust Core Engine

Directly calls Windows kernel APIs through multithreaded Rust worker pools. Directory listings with 100,000+ files load without blocking the main event loop, utilizing zero-copy metadata streaming.

  • ✓ Rayon threadpool parallel directory scanner
  • ✓ Instant parallel cold starts via cached index snapshots
  • ✓ Virtual DOM pagination powered by TanStack Virtual

True Dual-Pane & Miller Columns

Side-by-side synchronized explorer panes let you organize, compare, and drag-and-drop between directories in a single unified window.

  • ✓ Hotkey toggle with Ctrl + \
  • ✓ Miller Columns hierarchical drill-down

Super File Transfer System

Never lose progress to random overwrite prompts. Asynchronous background queue with live transfer speed, ETA calculation, and batch conflict resolution.

  • ✓ Interactive conflict dialogs: Auto Rename, Skip, Overwrite
  • ✓ Real-time byte-level throughput charts

Instant Spacebar QuickLook

Inspect images, code, Markdown, PDFs, and video files in milliseconds by tapping Space without waiting for heavy external apps.

  • ✓ Syntax highlighted code previews
  • ✓ Image metadata, EXIF & SHA256 checksum inspector

Strict Local-First Privacy

Zero telemetry. No cloud account logins, no telemetry endpoints, and no background metric scraping. Your files and paths never leave your local machine.

  • ✓ 100% offline capable
  • ✓ Open source codebase on GitHub

Modern Stack

Built with state-of-the-art systems programming.

How Nova Explorer delivers instant responses without the memory overhead of Chromium web apps.

Core Backend
Rust 2021 & Tauri v2

Native Windows Win32 bindings and Webview2 runtime sharing eliminate the need to bundle redundant 150MB Chromium browsers.

Concurrency
Rayon & Sysinfo

Non-blocking disk reads, parallel checksum generation, and real-time disk drive telemetry computed asynchronously.

User Interface
React 19 & Vite 8

Concurrent React 19 rendering with transitions guarantees 60 FPS scrolling even during intensive disk transfer operations.

DOM Optimization
TanStack Virtual

Dynamic viewport virtualization renders only visible rows, guaranteeing fixed minimal DOM memory usage.
