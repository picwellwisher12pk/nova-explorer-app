## 🚀 Key Features

- **Blazing Fast Cold Start**: <12ms startup latency.
- **True Dual-Pane & Miller Columns**: Side-by-side synchronized explorer panes.
- **Custom Preview Handlers & Associations**: Full control over media, code, markdown, audio/video renderers.
- **Ambiguous .ts Content Sniffing**: Microsecond dynamic packet sniffing separating video streams from code.
- **Super File Transfer Engine**: Real-time throughput graph, conflict resolution (Auto-Rename, Skip, Overwrite, Keep Newer).
- **Instant Spacebar QuickLook**: Millisecond previews of code, markdown, media, and images.
- **Zero Telemetry**: 100% offline, local-first privacy.
